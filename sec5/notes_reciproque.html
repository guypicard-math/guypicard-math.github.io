La réciproque d'une fonction

Définition générale, lien graphique et étude des fonctions du 1er degré, racine carrée et du 2e degré.

0. Qu'est-ce qu'une réciproque ?

Cliquer sur les zones pointillées pour révéler

On obtient la réciproque d'une fonction \(f\) en intervertissant les variables \(x\) et \(y\) dans sa règle ou dans ses couples de coordonnées : chaque point \((x, y)\) de \(f\) devient le point \((y, x)\) sur sa réciproque.

Effet graphique

La courbe de la réciproque est l'image de celle de \(f\) par une réflexion par rapport à la droite d'équation \(y = x\) .

Domaine et image

\(\text{dom } f^{-1} = \) \(\text{ima } f\) \(\text{ima } f^{-1} = \) \(\text{dom } f\)

Notation \(f^{-1}(x)\)

On utilise la notation \(f^{-1}(x)\) uniquement lorsque la réciproque est elle-même une fonction .

1. Exemples guidés par famille de fonctions

Exemple A

Fonction polynomiale du 1er degré : \(f(x) = 2x - 6\)

Propriétés de départ : \(\text{dom } f = \mathbb{R}\) et \(\text{ima } f = \mathbb{R}\).

  1. Remplacer \(f(x)\) par \(y\) : \(y = 2x - 6\)
  2. Intervertir \(x\) et \(y\) : \(x = 2y - 6\)
  3. Isoler \(y\) :

    \(x + 6 = 2y\)

    \(y = \dfrac{x + 6}{2} = \dfrac{1}{2}x + 3\)

  4. Conclusion : Comme chaque valeur de \(x\) donne une seule valeur de \(y\), la réciproque est une fonction :
    \(f^{-1}(x) = \dfrac{1}{2}x + 3\), avec \(\text{dom } f^{-1} = \mathbb{R}\) et \(\text{ima } f^{-1} = \mathbb{R}\).

Les deux droites se croisent sur l'axe \(y = x\).

Exemple B

Fonction racine carrée : \(f(x) = 2\sqrt{x - 1} + 3\)

Étape 0 (indispensable) : Identifier le domaine et l'image de \(f\) avant de commencer.
\(\text{dom } f = \) \([1, +\infty[\) \(\text{ima } f = \) \([3, +\infty[\)
  1. Intervertir \(x\) et \(y\) : \(x = 2\sqrt{y - 1} + 3\)
  2. Isoler la racine, puis élever au carré :

    \(x - 3 = 2\sqrt{y - 1}\)

    \(\dfrac{x - 3}{2} = \sqrt{y - 1}\)

    \(\left(\dfrac{x - 3}{2}\right)^2 = y - 1 \implies y = \dfrac{1}{4}(x - 3)^2 + 1\)

  3. Préciser la restriction du domaine : Puisque \(\text{dom } f^{-1} = \text{ima } f\), on ne garde qu'une seule branche de la parabole :
    \(f^{-1}(x) = \dfrac{1}{4}(x - 3)^2 + 1\), pour \(x \in [3, +\infty[\) (ou \(x \ge 3\)).

La réciproque est une demi-parabole (\(x \ge 3\)).

Exemple C

Fonction polynomiale du 2e degré : \(f(x) = (x - 2)^2 + 1\)

Propriétés de départ : \(\text{dom } f = \mathbb{R}\) et \(\text{ima } f = [1, +\infty[\).

  1. Intervertir \(x\) et \(y\) : \(x = (y - 2)^2 + 1\)
  2. Isoler \(y\) (attention au \(\pm\) lors de la racine carrée !) :

    \(x - 1 = (y - 2)^2\)

    \(\pm\sqrt{x - 1} = y - 2\)

    \(y = \pm\sqrt{x - 1} + 2\)

  3. Analyse : Cette réciproque est-elle une fonction ?

    Non ! Pour tout \(x > 1\), il existe 2 valeurs de \(y\) (échec du test de la droite verticale).

    Pour obtenir une fonction réciproque, on doit restreindre le domaine de \(f\) à partir du sommet \(h = 2\) :

    • Si \(x \in [2, +\infty[\), alors \(f^{-1}(x) = +\sqrt{x - 1} + 2\)

    • Si \(x \in ]-\infty, 2]\), alors \(f^{-1}(x) = -\sqrt{x - 1} + 2\)

La droite verticale rouge coupe la réciproque en 2 points : ce n'est pas une fonction.

2. Question de réflexion

Sans calculer la règle de la réciproque, comment peut-on savoir graphiquement à partir de la courbe de \(f\) si sa réciproque sera une fonction ? Explique ton raisonnement.

On applique le test de la droite horizontale sur le graphique de \(f\) ! Comme les axes \(x\) et \(y\) sont inversés, une droite horizontale sur \(f\) devient une droite verticale sur la réciproque. Si toute droite horizontale coupe la courbe de \(f\) au plus une fois (comme pour le 1er degré ou la racine carrée), alors sa réciproque est une fonction.

3. Mon exemple

Choisis ta propre fonction (1er degré, racine carrée ou 2e degré), détermine sa réciproque et trace les deux courbes ainsi que la droite \(y = x\).

Démarche algébrique :

⭐ À retenir

  • 4 étapes algébriques : remplacer \(f(x)\) par \(y\), intervertir \(x\) et \(y\), isoler \(y\), puis vérifier le domaine/l'image.
  • Symétrie : \((a, b) \in f \iff (b, a) \in f^{-1}\) (réflexion par rapport à \(y = x\)).
  • 1er degré : réciproque toujours du 1er degré (si \(a \neq 0\)).
  • Racine carrée : réciproque = une demi-parabole (domaine restreint par \(\text{ima } f\)).
  • 2e degré : réciproque = relation à deux branches (\(\pm\)), sauf si on restreint le domaine de \(f\) à partir de \(x = h\).

🛑 Erreur fatale

1. Oublier la restriction du domaine (racine carrée) :

Pour \(f(x) = \sqrt{x} + 4\) (\(\text{ima } f = [4, +\infty[\)) :

\(f^{-1}(x) = (x - 4)^2\) pour tout \(x \in \mathbb{R}\)

✓ \(f^{-1}(x) = (x - 4)^2\), pour \(x \ge 4\)

2. Confondre réciproque et inverse multiplicatif :

\(f^{-1}(x) = \dfrac{1}{f(x)}\)

✓ L'exposant \(-1\) sur \(f\) désigne la réciproque, pas l'inverse !

5. Pratique

🍏 Doux — Application directe

Détermine la règle de la fonction réciproque de \(f(x) = -3x + 12\), puis donne son domaine et son image.

\(x = -3y + 12 \implies x - 12 = -3y \implies y = -\dfrac{1}{3}x + 4\)

Réponse : \(f^{-1}(x) = -\dfrac{1}{3}x + 4\), avec \(\text{dom } f^{-1} = \mathbb{R}\) et \(\text{ima } f^{-1} = \mathbb{R}\).

🌮 Moyen — Attention au signe et au domaine !

Détermine la règle de la fonction réciproque de \(g(x) = -\sqrt{2(x + 3)} + 5\) en précisant obligatoirement son domaine.

D'abord : \(\text{dom } g = [-3, +\infty[\) et \(\text{ima } g = ]-\infty, 5]\) (car \(a = -1 < 0\)).

\(x = -\sqrt{2(y + 3)} + 5 \implies x - 5 = -\sqrt{2(y + 3)} \implies 5 - x = \sqrt{2(y + 3)}\)

\((x - 5)^2 = 2(y + 3) \implies \dfrac{1}{2}(x - 5)^2 = y + 3 \implies y = \dfrac{1}{2}(x - 5)^2 - 3\)

Réponse : \(g^{-1}(x) = \dfrac{1}{2}(x - 5)^2 - 3\), pour \(x \in ]-\infty, 5]\) (soit \(x \le 5\)).

🌶️ Épicé — Choix de la bonne branche

Soit la fonction du 2e degré \(h(x) = -2(x - 4)^2 + 18\) définie sur le domaine restreint \(x \in ]-\infty, 4]\).
a) Détermine la règle de \(h^{-1}(x)\) ainsi que son domaine et son image.
b) Vérifie algébriquement si le point \((0, 1)\) appartient à la courbe de \(h^{-1}\).

a) On a \(\text{dom } h = ]-\infty, 4]\) et \(\text{ima } h = ]-\infty, 18]\).

\(x = -2(y - 4)^2 + 18 \implies x - 18 = -2(y - 4)^2 \implies -\dfrac{1}{2}(x - 18) = (y - 4)^2\)

\(y = \pm\sqrt{-\dfrac{1}{2}(x - 18)} + 4\)

Puisque \(\text{ima } h^{-1} = \text{dom } h = ]-\infty, 4]\), on doit avoir \(y \le 4\), donc on choisit le signe négatif :

\(h^{-1}(x) = -\sqrt{-\dfrac{1}{2}(x - 18)} + 4\), avec \(\text{dom } h^{-1} = ]-\infty, 18]\) et \(\text{ima } h^{-1} = ]-\infty, 4]\).

b) \(h^{-1}(0) = -\sqrt{-\dfrac{1}{2}(0 - 18)} + 4 = -\sqrt{9} + 4 = -3 + 4 = 1\). Oui, le point \((0, 1)\) appartient à \(h^{-1}\) !
